git unpack-objects — Unpack objects from a packed archive

Synopsis git unpack-objects [-r] [-q] < <pack-file> Description The git unpack-objects command reads a packfile from stdin and writes its contents as individual loose objects into the object database. This is the inverse of git pack-objects. In day-to-day use, git unpack-objects integrates closely with shell aliases, editor plugins, and continuous integration. Common Options OptionDescription -nDry-run: show what would be unpacked. -qQuiet, no progress. -rRecover what's possible from a damaged pack. --strictRefuse to write objects with broken links. Examples git unpack-objects < pack-abc.pack # Explode pack into loose objects git unpack-objects -r < broken.pack # Salvage what we can from a damaged pack git unpack-objects -n < somepack.pack # Just preview what would be unpacked Common Mistakes Unpacking a huge pack creates many tiny files and slows the filesystem. Almost every operational scenario prefers keeping the pack intact.
